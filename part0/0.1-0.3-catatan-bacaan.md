# Catatan bacaan 0.1-0.3 (tidak wajib dikirim, hanya catatan)

Tutorial Mozilla yang dibaca (tautan dari materi Part 0b, tersambung ke versi MDN terbaru):

## 0.1 HTML: "HTML: Creating the content"
https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Creating_the_content
- HTML adalah bahasa markup untuk menyusun isi halaman; dokumen terdiri dari elemen bertag (`<html>`, `<head>`, `<body>`).
- Gambar disisipkan dengan `<img>` (atribut `src` dan `alt`); teks ditandai dengan `<h1>`-`<h6>`, `<p>`, `<ul>`/`<ol>`/`<li>`, `<strong>`, `<em>`.
- Tautan dibuat dengan `<a href="...">`.

## 0.2 CSS: "CSS: Styling the content"
https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Styling_the_content
- CSS menata tampilan lewat aturan `selector { properti: nilai; }`, dimuat dari berkas `.css` dengan `<link rel="stylesheet">`.
- Setiap elemen adalah kotak (content, padding, border, margin); warna, font, perataan teks, dan penempatan gambar diatur lewat properti.

## 0.3 Formulir HTML: "Your first form"
https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Your_first_form
- Formulir dibuat dengan `<form action="..." method="GET|POST">`; kolom isian memakai `<input>`, `<textarea>`, `<button>`, dan setiap kolom diberi `<label>` serta atribut `name`.
- Saat dikirim, browser mengirim pasangan `name=nilai` ke alamat `action`; GET menaruhnya di URL, POST di badan permintaan (kaitannya dengan form catatan di aplikasi contoh pada 0.4).
